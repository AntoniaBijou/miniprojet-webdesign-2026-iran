# miniprojet-webdesign-2026-iran
Mini-projet de Web Design (Mars 2026) : Création d'un portail d'informations sur la guerre en Iran. Comprend un FrontOffice optimisé pour le SEO (URL rewriting, balises méta, structure Hn), un BackOffice de gestion de contenu, une base de données Postgres et un déploiement conteneurisé avec Docker.
